# Security policy

Do not report vulnerabilities in public issues when they could expose private scan data, paths, credentials, or a way to execute unintended code through crafted input.

Instead, contact the maintainer privately through the contact method listed on the repository profile and include a minimal synthetic reproduction. The project currently has no supported security-release SLA.

Never include an E57 scan, architectural plan, client identity, property address, or access token in a report.
